Presentation time or decoding time.

Bitrate = packet bits in each fixed 1-second interval ÷ 1 second. By default, only full intervals within the stream’s packet timeline are included.

Include partial seconds to keep the start/end intervals too. They are still divided by 1 second, so their values may be lower.

Bandwidth planning estimate

—

Estimate = measured rate × (1 + overhead / 100) × (1 + headroom / 100). Defaults of 5% overhead and 20% headroom are editable assumptions, not measured requirements. Packet rates exclude packaging; segment rates already include it. Single-track results omit other tracks. Buffering, bursts within intervals, and segment download deadlines can require more bandwidth.

HLS / DASH segment analysis

Select a local package folder, or a manifest and its segment files together. No remote downloads. Rate = segment file bytes × 8 ÷ manifest playback duration. Includes segment packaging; excludes network overhead and initialization downloads. For separate audio/video renditions, analyze each and account for both.
